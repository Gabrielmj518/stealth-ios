iPhone app

Run Stealth on the iPhone itself: same map and controls, no PC needed once it is set up. It works through LocalDevVPN and a pairing file.

  1. 1
    LocalDevVPNFree loopback VPN from the App Store. Keep it ON while spoofing.
  2. 2
    Download Stealth for iPhoneYour build on GitHub (user/repo). Saved in Downloads.
  3. 3
    Install it on the iPhoneiloader: sign in with your Apple ID and install the .ipa over USB.
  4. 4
    Pairing fileCreate it with idevice_pair, then import it in the app once.
  5. 5
    Alternative: LocusA ready-made open-source app that does the same.

Apps installed with a free Apple ID expire after 7 days and need to be re-signed.
