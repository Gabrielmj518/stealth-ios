# Third-party software

* **idevice** (MIT) - https://github.com/jkcoxson/idevice - Rust library used to talk to the iPhone's developer services. It is downloaded and compiled during the build.
* **Leaflet** (BSD-2) - https://leafletjs.com - map rendering inside the app.
* Map tiles: Esri and OpenStreetMap contributors. Search: Nominatim. Routes: OSRM.
* The sequence of idevice calls used for on-device location simulation follows the approach of the open-source app **Locus** (MIT) - https://github.com/ChrisMack32/Locus
* **LocalDevVPN** (App Store, by Jackson Coxson) provides the loopback tunnel the app connects through.
